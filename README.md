# 강수량에 따른 대중교통 이용률 비교

## 프로젝트 개요
본 프로젝트는 2024년 서울교통공사 승하차 데이터와 기상청(AWS) 기상 데이터를 결합하여, 강수 여부가 대중교통(지하철) 이용에 미치는 영향을 분석한 연구입니다.  
목표는 강수량 변화에 따른 지하철 이용 패턴을 이해하고, 날씨에 대한 시민들의 교통 수요 탄력성을 평가하는 것입니다.

---

## 데이터 출처
1. **서울교통공사**: 2024년 역별 일별 시간대별 승하차 인원 데이터  
   - 컬럼: 날짜, 호선, 역번호, 역명, 구분, 시간대별 승/하차 인원
2. **기상청(AWS)**: 2024년 1월 ~ 12월 수도권 관측소 기상 데이터  
   - 컬럼: 시군명, 지점번호, 관측일자, 관측시간, 기온, 풍속, 습도, 시간누적강우량 등

---

## 데이터 전처리 및 가공
1. 모든 CSV 파일을 UTF-8 인코딩으로 통일  
2. 대중교통 데이터와 기상 데이터를 시간 단위(`hour`) 기준으로 통합  
3. '24시 이후' 데이터는 다음날 0시로 변환  
4. 수도권 각 관측소 데이터를 평균하여 시간별 강수량, 기온, 풍속, 습도 계산  
5. 시간대별 승객 수 및 기상 데이터를 병합하여 최종 분석 데이터 생성

---

## 분석 방법
1. **호선별 이용객 수 합계**  
2. **역별 이용객 수 Top 10**  
3. **강수량 증가에 따른 시간당 이용객 수 변화 추세** (산점도 및 회귀 분석)  
4. **날씨별 평균 이용객 수 비교** (비 옴 vs. 비 안 옴)

---

## 주요 분석 결과
- 2024년 가장 많은 승객이 이용한 호선: **2호선**  
- 주요 혼잡 역: **잠실, 홍대입구, 강남**  
- 강수량이 증가할수록 승객 수가 일부 감소하는 경향 관찰  
- 그러나 비가 오는 날과 오지 않은 날의 시간당 평균 이용객 수에는 큰 차이가 없음  
- 서울 지하철은 통근/통학용 필수 이동 수단으로, 단기적인 기상 변화에도 수요가 비교적 비탄력적임

---

## 시사점
- 지하철은 악천후에도 시민들이 신뢰할 수 있는 필수 교통수단임  
- 지하철은 비의 영향을 직접 받지 않는 지하 구간이 많아 날씨 민감도가 낮음  
- 버스나 자전거와 비교 분석 시 더 다양한 기상 민감도를 확인 가능

---

## 한계점 및 개선 방향
- 기상 데이터 오류 가능성: 지자체 센서 관리 부족으로 일부 데이터 신뢰도 저하  
- 지하철만 분석: 향후 버스, 자전거 등 다른 교통수단과 비교 필요

---

## 사용 방법
1. `merged_df.csv` 파일을 통해 시간대별 승객 수와 기상 데이터를 확인  
2. Python `pandas`, `seaborn`, `matplotlib` 등을 사용하여 추가 분석 및 시각화 가능

---
